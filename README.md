# AI 画布表格工具 0.2.0

**本地测试版 · Windows x64 · Adobe Illustrator 2024（28.5）**

正文由插件保存和编辑，画布上的字由矢量路径组成。插件不创建正文文字框，也不使用隐藏、临时文字框或原生文字转曲。合并、拆分和增删行列集中在“画布表格”侧栏。

已完成自动模拟、Windows 文字排版、输入消息和云端编译检查；Illustrator 内的实际操作由你进行本地验收，尚未记为通过。

## 安装

1. 保存文件并退出 Illustrator。
2. 解压本包，将 `IllustratorTableTool.aip` 放进专用的插件文件夹。升级旧测试版时替换同名文件，加载目录中只保留一份。
3. 在 AI“编辑 → 首选项 → 增效工具和暂存盘”中，将该文件夹设为“其他增效工具文件夹”，重启 AI。
4. 新建测试文档，打开“窗口 → 画布表格”。“对象 → 画布表格”提供相同命令。

卸载时退出 AI，移走该 `.aip` 或取消上述文件夹设置即可。插件需要 Windows 10 1903 或更新系统提供的文字组件；面向 AI 28.5，本次未验证其他 AI 版本。

## 使用

- 点击侧栏“新建表格”，填写行列和毫米尺寸，确定后在画布单击放置。
- 表格工具单击选格，按住 Shift 再单击另一格选择矩形区域。
- 双击格内进入文字编辑，单击定位光标、拖动选择文字。支持中文输入法、Enter 换行、复制剪切粘贴、删除和方向键。
- Tab 移到下一格，Shift+Tab 移到上一格；合并格只访问一次。最后一格按 Tab 新增一行，达到数量上限时拒绝新增。
- 输入法组字期间按 Esc 取消组字；无组字时按 Esc 退出文字编辑。
- 在侧栏合并、拆分、增删行列和设置单元格样式；拖动表格边线调整行高列宽。
- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，Ctrl+S 调用 AI 保存。

上限为 100 行、50 列、总计 2000 格，最小行高列宽 2 毫米。字体取自 Windows 可用字体；缺字、过长文字或过复杂字形会拒绝本次修改。内容超出格子时保留文字数据并显示溢出提示，可扩大单元格查看。

合并内容按行序用换行连接。未改字时拆分恢复原格文字与样式；合并后改过字，再拆分时修改内容留在左上格，其余原格恢复原内容。当前样式设置作用于整个所选单元格。

## 本地测试步骤

建议在新建文档中依次验证：

1. 创建 2×3 表格，检查侧栏能否停靠、按钮是否生效。
2. 双击输入“中文 ABC 123”，换行；检查输入法候选、确认、取消，以及是否重复插字。
3. 拖选格内文字，复制、剪切、粘贴；测试 Tab、Shift+Tab 和末格自动增行。
4. Shift 选择两格并合并、拆分，再测试合并后改字的拆分规则。
5. 增删行列、拖动边线、调整底色和字号；分别撤销、重做。
6. 保存 `.ai`，关闭重开后继续改字；复制整表后修改副本，检查原表是否独立。
7. 输入“O8中文”，导出 PDF，检查孔洞、边框、裁切及画面中没有光标或选择高亮。

如果出现问题，请记录具体步骤、AI 版本和截图；保留出问题的测试文件，方便定位。

## 文件与兼容

文字数据随 `.ai` 表格组保存。没有插件时仍能显示和导出矢量外观，重新改字需要插件，AI 自带文字工具不能编辑这些字形。

PDF 中表格文字为轮廓，无法像普通 PDF 文字一样搜索或选择。旧版使用文字框的开发表格不会自动转换，请新建表格测试这一版。旋转、倾斜的表格及旋转后的画布视图暂不保证编辑。

此包关闭开发自动验收入口，不会自动创建测试文档或退出 AI。`SHA256SUMS.txt` 用于核对文件完整性。
