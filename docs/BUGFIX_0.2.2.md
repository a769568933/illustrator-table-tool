# 0.2.2：编辑入口预览与鼠标拖选

用户实测 0.2.1 双击仍无反应。日志已记录 edit.begin、window.ready、preview.ready、focus.queued，说明双击识别和输入窗口创建已执行，但旧日志没有证明预览非空或焦点真正取得。此次不将旧版“preview.ready”当作编辑成功证明。

新增 SDK 编辑入口回归：使用有明确坐标定义的画布范围与窗口可见区域，断言 EditController.begin 后实际向辅助绘制提交非空图像。该测试在原实现中真实失败（构建 39101792185，editor_entry 失败，其余 9 项通过）。旧代码把可见区域直接当作作品坐标再转换，可能得到上下反向、空交集；现在改用 SDK 明确为作品坐标的 GetDocumentViewBounds，并规范化转换后的边界顺序。实际裁切仍由 Illustrator 的辅助绘制处理。

焦点日志新增 dispatch、ready、failed、gained、lost；退出编辑会注明工具切换、文档切换、文档关闭或对象变动。只记阶段，不记录用户正文。桌面检查工具连接失败，尚未自动操作或验证真实 AI。

新增鼠标拖选：从格内按下，拖过其他格选择连续矩形；反向拖选保持起点，跨合并格包含完整合并格，拖出表格限制到最外格，松开不修改模型且不产生结构撤销。边线起拖仍调整尺寸；格内文字编辑拖动仍选字。Esc 退出编辑后可拖选单元格。

本机 core_tests 从拖选断言失败转为 267 项通过；模拟后端从未知 dragSelect 动作失败转为 7 个模拟用例通过，包含既有 480 次结构操作。浏览器检查覆盖双击、输入、Tab、平均分布及反向拖选；修复了捕获指针过早导致双击目标丢失的问题。真实 AI 中的输入仍需用户验证，不能用这些结果声称已验收。
