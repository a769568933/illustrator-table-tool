# 0.2.4：透明背景、字体与文字对齐

用户确认：侧栏直接选择字体和字号，水平左／中／右和垂直上／中／下分别设置；新表格默认透明，可切换为有底色；修改作用于所有选中的完整单元格。保持无正文文字框、侧栏表格操作和用户自行实机验收的约束。

## 实现

- 新表格默认关闭单元格填充；边框保持。底色选色后可启用填充，侧栏可快速切换透明。编辑预览通过带 alpha 的 PNG 辅助绘制，不以白色像素盖住透明区域，不向文档写入图片。
- 侧栏枚举 Windows 字体家族，选择后应用；字号为独立数字参数。修改字体不重置原有颜色和字号；修改对齐不覆盖各格底色、边框或字体。
- 垂直对齐按整个文字块（所有段落与自动换行）的高度计算空余空间；字形轮廓、光标、文字选择与命中共同使用偏移。溢出时保持顶部锚点，避免把前半段文字移到单元格外而无法编辑。
- 保存升级到 ITT4，在全部单元格和合并快照中保存填充开关及垂直对齐。读取旧 ITT1/2/3 核心数据时保持原来不透明、顶部对齐的默认语义；原生适配器读取既有 ITT3 无文字框表格。旧文字框表格仍不自动转换。
- 混合字体／字号／对齐的多格选区显示空项、未选按钮或不确定的透明状态；更改某项仅统一该项。
