# Illustrator 28.5 验证记录

## 0.2.0 无文字框版本 · 2026-10-18

**交付范围：本地测试版。用户要求完成后自行进行本地测试，本轮未安装、重启或操作 Illustrator。**

新版完全替换旧文字框实现：正文保存在表格数据中，DirectWrite 在内存排版并直接提取字形路径，文档只保存矢量组、路径和裁切。输入窗口为自定义 Windows 类，不使用 EDIT / RichEdit。编辑预览为临时辅助显示，不写入文档。

已运行的自动检查：

- Windows 原生构建的 9 个 CTest 目标涵盖核心、富文本、编辑、会话、字形排版、自定义输入和预览、套件作用域、对象保护、宿主上下文。接通版本构建：[39085639101](https://github.com/a769568933/illustrator-table-tool/actions/runs/39085639101)。
- 模拟器共用 C++ 核心：5 个测试，包含既有 480 次结构操作，以及中文替换、换行、完整字符删除、合并格 Tab、末格增行、格式及保存数据往返。
- 独立浏览器模拟：8 项流程通过；实际双击进入画布编辑、输入 TEST、Tab 到下一格通过。模拟正文不用 DOM 输入框。
- SDK 边界测试检查隐藏文字对象拒绝、过期或异文档句柄保护，以及创建路径失败时请求回滚；这不等于真实 AI 的事务验收。

待用户在 Illustrator 28.5 测试：侧栏停靠；搜狗及微软拼音的候选确认、取消和不重复插字；文字拖选与剪贴板；Tab；合并拆分和增删行列；每项操作的撤销重做；25% / 100% / 400% 缩放、DPI 与滚动；保存关闭重开继续编辑；复制表格独立；整表移动缩放；RGB / CMYK；锁定隐藏；PDF 孔洞、裁切及没有辅助高亮。操作步骤见根目录 README 的“本地测试步骤”。以上均未标为通过。

正式交付包关闭 `TABLE_HOST_ACCEPTANCE`，不会自动创建测试文档或退出 AI。旧版文字框表格不自动转换。Windows 10 1903+，PDF 表格文字为轮廓；旋转、倾斜及旋转画布编辑暂不保证。
