## 2. 方案选择

### 采用：C++ 原生插件与画布表格工具

使用与 Illustrator 2024 对应的 Adobe C++ SDK，交付 `.aip` 插件。插件注册表格工具和菜单命令，直接处理画布上的选择及拖动操作。创建参数和样式通过简体中文对话框提供，基础编辑不依赖网页面板。

Adobe 官方说明支持 C++ 插件、自定义工具以及文字处理；具体的文字激活、工具事件、撤销和持久化接口，必须以取得的 2024 SDK 为准，并经过 28.5 实机验证。

### 不采用：仅使用 CEP 面板

面板适合数据录入和样式设置，但不能单独承担用户已选择的完整画布工具交互。后续如增加属性面板，它只作为原生工具的辅助界面。

### 不采用：独立网页或 JSX 表格生成器

这些方式可生成图形，但不能作为本次直接编辑表格的主要交付。

## 3. 第一版操作设计

### 创建表格

菜单提供“表格工具 → 新建表格”，填写行数、列数、总宽度、总高度，默认 4 行 4 列。尺寸以毫米显示，内部换算为点。用户随后在画布单击放置表格左上角，Esc 取消。

首版允许 1–100 行、1–50 列，总格数不超过 2,000。所有尺寸必须为正数，最小行高和列宽为 2 毫米。超限时给出明确说明，不创建部分表格。

### 选择单元格

- 使用表格工具，单击选择单元格。
- Shift + 单击选择由起点和终点组成的矩形区域。
- 点击表格外部清除选择，Esc 退出当前编辑或拖动状态。
- 选区使用辅助高亮显示，高亮不进入导出文件和印刷内容。
- 文档缩放后仍按屏幕距离判断边线命中，避免放大或缩小时难以选中。

### 调整行高和列宽

- 靠近内部边线时改变光标，按住拖动实时显示预览。
- 拖动内部竖线只调整两侧相邻列，保持表格总宽不变；横线同理。
- 拖动右侧或底部外框调整最后一列或最后一行，同时改变表格总尺寸。
- 合并区域中的隐藏线段不能被拖动；可见部分仍可调整对应逻辑行列。
- 达到最小尺寸时停止继续缩小，不产生负尺寸和交叉边线。
- 一次完整拖动只生成一条撤销记录；Esc 取消预览。

### 画布文字编辑

- 目标交互为双击单元格进入画布内文字编辑，支持中文输入法、换行、复制粘贴和文本选择。
- 优先使用 Illustrator 自身的文字对象与文字编辑能力，保持可编辑文字，不转为轮廓。
- 文字编辑必须与原生表格工具的鼠标事件正确切换，输入时不截获输入法按键。
- 文字溢出时显示辅助提示，不自动缩小字号或丢弃内容。
- 这是首个宿主验证关卡：若 SDK 无法可靠激活或保持原生文字编辑，应报告具体实测结果并调整方案，不能将弹窗输入冒充为画布编辑完成。

### 结构编辑

- 命令提供在选区前后插入行列、删除选中行列。
- 删除后至少保留一行一列；禁止删除整张表，整表删除使用 Illustrator 的对象删除操作。
- 合并仅接受完整的矩形区域，不能切开已有合并单元格。
- 合并后文本按从左到右、从上到下顺序以换行连接，非左上角单元格原始内容保存在内部数据中。
- 拆分恢复原逻辑网格。合并后的文本未被修改时，各格恢复原始内容；合并后的文本被修改时，新内容保留在左上角，其余格恢复各自原始内容。此规则优先保留内容，可能产生用户需要整理的重复文字。
- 在合并区域内部插入行列时扩展该区域跨度；删除跨越部分时缩减跨度，保留仍存在的内容及有效锚点。

### 基础样式

对所选单元格设置底色、边框颜色和粗细、字体、字号、文字颜色、水平对齐与上下内边距。首版文字竖向排版采用顶部对齐；精细的垂直居中、每条边独立样式以及复杂段落样式留到后续版本。

颜色使用文档的 RGB 或 CMYK 模式，避免印刷文档被无提示转换。共享边框只绘制一次，避免重叠线条造成描边加深。

## 4. 模块及数据流

1. **表格模型**：行高、列宽、合并跨度、稳定单元格编号、样式与内容映射；不依赖 Illustrator，便于在云端运行单元测试。
2. **几何与命中测试**：计算格子范围、可见边线、选区和拖动约束；在文档坐标与屏幕坐标之间转换。
3. **宿主适配**：插件加载、工具注册、文档事件、画布辅助绘制、对象创建及文字编辑接入。
4. **文档存储与同步**：将版本化表格结构存进文档对象的持久数据，并关联实际文字对象。原生文字编辑后读取真实文字内容，避免旧模型覆盖新输入。
5. **命令与撤销**：用户操作先计算候选状态，通过校验后提交；失败时恢复原对象和数据。
6. **中文界面**：新建参数、样式设置和结构命令；错误信息应说明如何继续操作。

表格采用普通 Illustrator 对象组，包含原生文字框、填色路径、共享边线路径和用于定位的外框路径。组对象的持久字典存储版本化表格模型，子对象存储稳定标识。采用此结构便于原生文字工具编辑，也能在未安装插件时保留可见内容。

外框的实际路径坐标作为整表位置和轴向缩放的参照，重新进入表格编辑时据此同步模型尺寸；关联文字框的实际内容是文字的最终来源。宿主适配必须验证这些持久字典与文字框能在 28.5 保存重开后正常读取；验证失败时需要修改本设计，不能无提示切换为另一种对象机制。

首版保证未旋转、未倾斜的表格可编辑。标准选择工具对整表的移动、复制和轴向缩放必须验证；旋转、倾斜后的表格需明确提示恢复方向后再使用表格工具，不错误改写几何。用户可主动执行“转换为普通对象”，保留可见路径和文字，结束结构化表格编辑。

## 5. 保存和兼容行为

- 保存为 `.ai` 后关闭再打开，行列、合并和文字必须仍可识别与编辑。
- 同文档复制表格应得到独立实例，编辑一张不影响另一张。
- 用户直接修改文字后，下一次表格操作保留最新文字。
- 没有插件时，应保留可见的表格外观；结构化操作需要安装插件。
- 对无法识别的数据版本、缺失关联对象、锁定或隐藏的表格停止修改并说明原因。
- 首版只承诺验证过的 Illustrator 28.5 Windows x64，不笼统宣称支持所有 Adobe 版本。
