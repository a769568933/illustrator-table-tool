# 无文字框的 Illustrator 表格编辑器

日期：2026-10-18  
状态：用户于 2026-10-18 回复“确认”，方案已批准；尚未实现。本方案取代 2026-10-16 方案中的原生文字框、ATE 编辑和隐藏文字快照部分。

## 已确认的要求

- 运行于 Windows x64、Illustrator 2024 28.5。
- 尽量接近 InDesign 的格内编辑方式；合并、拆分、增删行列等操作放在侧边栏。
- **底层也不能使用文字框**。不能使用区域文字、点文字、隐藏文字框或临时文字框来输入、排版、显示、保存格式或转曲。
- 使用现有公开 GitHub 仓库和云端编译。先模拟测试，再做 Illustrator 实机验收，满足要求后交付。

## 方案与边界

采用“插件保存文字和格式，自行处理输入，输出矢量字形路径”的方案。表格是一份统一数据；每格不是 Illustrator 文字对象。Windows DirectWrite 只在内存中计算字形、位置和命中结果，字形轮廓直接生成 Illustrator 路径，不经过 AI 文字工具或文字转曲命令。

栅格图片也能避免文字框，但缩放、印刷和再次编辑不符合本项目目标，因此不采用。保留原生文字对象的方案已被用户明确否决。

文字可通过插件再次编辑；关闭插件后，AI 能显示、缩放和导出已有矢量外观，但 AI 自带文字工具不能直接改字。PDF 中表格文字以轮廓显示，不具有普通 PDF 文字的搜索和选字能力。首版保持横排中英文、数字、多行文字及现有表格样式范围，不承诺完整复刻 InDesign 的跨页表、脚注、竖排和彩色字体功能。

## 用户操作

1. 侧栏新建表格，在画布单击放置。保留现有行列、毫米尺寸及数量限制。
2. 表格工具单击选择格；双击格内进入文字编辑，在点击处显示光标。编辑中单击定位、拖动选择文字，支持中文输入法、复制、剪切、粘贴、删除和换行。
3. Tab 移至下一可见单元格，Shift+Tab 移至上一格，合并格只停留一次。最后一格按 Tab 新增一行；达到原有行数或总格数上限时保留当前位置并说明原因。第一格 Shift+Tab 保留当前位置。
4. Esc 在输入法组字中取消本次组字；无组字时退出文字编辑并选择当前格。Shift 单击另一格选矩形区域，合并区域按完整跨度扩展选区。
5. 侧栏负责合并、拆分、插入或删除行列、单元格样式。操作前先完成当前输入法提交；如果系统未能完成提交，则保留编辑状态并拒绝这次结构命令，不能丢失文字。
6. 合并内容按行序用换行连接。拆分恢复模型保存的原格内容和样式；合并后的文字发生修改时，沿用现有规则：修改内容留在左上格，其余原格恢复。侧栏提示该规则。
7. 拖动边线调整行高列宽；文字重新排版。溢出内容保留在数据中，画布裁切于格内并显示仅供编辑的溢出标记。

上述为本次建议的具体交互，用户可在审阅时修正；“底层零文字框”不属于可退让项。

## 组件与数据流

### 表格与文字模型

保留 TableModel 的格 ID、合并关系、行列尺寸、样式及保护规则。新增独立文字编辑状态：活动格、插入点、文字选区、输入法预编辑内容。预编辑内容只存在于会话中，确认后才写入文档。

文字为 Unicode 数据；格式范围保存字体、字号、颜色和段落对齐。合并前快照保存文字和格式数据，不保存任何隐藏 artwork。合并、拆分和行列调整必须同步更新格式范围。移动和删除按排版簇边界进行，不能截断 UTF-16 代理对或组合字符。

新数据使用独立版本标记与有界序列化。拒绝无效索引、格式范围、过大长度和重复格 ID；一张损坏表不影响其余表。已有带文字框的开发版文档不自动迁移，不把旧版读取或转曲逻辑作为新版回退路径。

### 文字排版与矢量输出

独立 Windows 排版模块使用 DirectWrite 完成字体选择、换行、字形簇、光标位置和文字选区的命中测试。字号与 AI 文档点数统一换算，屏幕缩放和 DPI 只影响显示坐标。

自定义字形绘制器取得字形轮廓，生成路径和复合路径，保留曲线、封闭轮廓、孔洞和填充规则。每格输出为内容路径组，与底色及共享边线分开。字体缺失时采用可用字体替代并提示；没有可用轮廓或超出资源上限时拒绝提交并保留原表，不能悄悄创建文字框。

先在内存中准备完整排版和路径数据，再进入 AI 文档修改。只更新受影响格；对输入长度、字形数和曲线段数设置有限预算。最终预算由性能试验记录，未验证性能前不宣称支持长篇排版。

### 输入和编辑显示

创建插件自己的 Windows 窗口类接收键盘与输入法消息，不使用 EDIT、RichEdit、隐藏文本框或 AI 文字焦点。输入法组字、候选框位置、提交和取消与格内光标关联。

画布辅助绘制光标、文字选区和组字预览，复用排版结果的坐标与轮廓。辅助显示不进入文档 artwork、保存和导出。滚动、缩放、切换文档、失去焦点时更新或清除辅助显示。侧栏尺寸等参数仍可使用普通数值控件；它们不承载表格正文。

### Illustrator 适配与撤销

新建表格的完整对象树只允许分组、路径、复合路径及需要的裁切路径。运行时不获取 AI TextFrame 或 ATE 编辑套件；删除旧版的文字框创建、文字焦点切换和隐藏格式快照路径。

键盘和侧栏事件经宿主应用上下文进入 SDK，文档操作仅在宿主允许的线程和回调中执行。保留当前文档、对象有效性、锁定隐藏、变换和损坏隔离检查。数据与外观在一次命令内一起更新；失败时恢复原数据和对象。

每次合并、拆分、行列操作、粘贴和输入法确认都形成可撤销操作；连续普通输入仅在同格、同输入状态下合并为一次输入操作。切格、移动光标、改变格式或失去焦点结束输入批次。撤销和重做后从持久数据恢复模型，不能依赖旧缓存。

## 验收条件

旧版已通过的文字框测试不能证明本方案通过。新增测试必须至少覆盖：

| 层面 | 必须验证 |
| --- | --- |
| 核心与模拟 | 中文和数字输入、多行、文字选区替换、代理对/组合字符删除、Tab 顺序、末格增行上限、合并拆分及格式范围恢复 |
| Windows 排版 | 中文字体替代、混合字号、换行、文字命中、光标、孔洞字形、曲线、点数与 DPI 换算；轮廓失败保持原数据 |
| 严格对象审计 | 新建、输入、粘贴、合并、拆分、复制、保存重开后，递归检查表格所有子对象，包括隐藏对象，TextFrameArt 数量始终为 0 |
| 严格输入审计 | 正文输入窗口为自定义类，无 EDIT/RichEdit/隐藏正文输入框；编译目标不包含旧版文字框适配实现 |
| Illustrator 实机 | 搜狗与微软拼音的候选、提交、取消；拖选文字；Tab/Shift+Tab；侧栏操作；行列缩放；25%/100%/400% 命中 |
| 持久与安全 | 一次操作撤销重做、复制实例独立、AI 保存关闭重开可改字、异常表隔离、删除/关闭/锁定/隐藏后的安全拒绝 |
| 输出 | PDF/打印矢量外观、字形孔洞和裁切正确，无光标、组字预览、选区或溢出提示；明确交付说明为轮廓文字 |

先运行核心与模拟、Windows 排版和对象审计，再安装开发构建进行实机验收。只操作新建测试文档；保存或退出用户文档仍由用户决定。未通过输入法、零文字框、撤销和保存重开这四项前，不交付成品。

## 实施顺序

先建立新文字模型和零文字框断言；再实现 DirectWrite 排版与路径输出；随后替换文档适配器，接入自定义输入和辅助绘制；最后接通侧栏命令，完成模拟、云端编译和实机验收。详细实施计划在本方案审阅后编写。

## 技术依据

- [Microsoft IDWriteTextLayout](https://learn.microsoft.com/en-us/windows/win32/api/dwrite/nn-dwrite-idwritetextlayout)：排版、字形簇和光标/选区命中接口。
- [Microsoft GetGlyphRunOutline](https://learn.microsoft.com/en-us/windows/win32/api/dwrite/nf-dwrite-idwritefontface-getglyphrunoutline)：直接提取字形轮廓。
- [Microsoft ImmGetCompositionStringW](https://learn.microsoft.com/en-us/windows/win32/api/immdev/nf-immdev-immgetcompositionstringw)：读取输入法组字与结果。

以上接口支持所选技术方向；尚未证明该方向在 Illustrator 28.5 内的焦点、输入法和辅助绘制集成已经通过。
